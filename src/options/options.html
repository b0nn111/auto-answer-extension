导入题目格式文档

文件必须是 UTF-8 JSON，根节点是数组；每一项代表一道题。

question
必填，题干文本。也兼容 questionText 或 q。
answer
必填，标准答案。也兼容 a 或 ans。
options
选填，选择题选项数组。也兼容 choices。
[
  {
    "question": "中国的首都是哪里？",
    "answer": "北京",
    "options": ["北京", "上海", "广州", "深圳"]
  }
]

导入时缺少题干或答案的条目会跳过，其他条目会写入本地题库。

数据来源说明 本地数据、云端 API 与隐私边界

本扩展会收集本地题库、免费搜题、本地 AI 和 AI API 的可用答案，按匹配度与置信度排序；已启用资料片段会作为 AI 的参考上下文。 资料库文件只保存在本地浏览器 IndexedDB 中；只有启用云端 API 或免费搜题时，相关题目和片段才会发送到对应服务。
